## Local Coder delegation
- Before coding a sub-task yourself while the local-coder MCP (`delegate_code_task`) is connected, delegate it if it is a clear, testable leaf in ≤3 files: helpers, mappings, DTOs, validators, parsers, type fixes, docstrings, small bug fixes, unit tests.
- Never delegate: architecture, auth/crypto, data migrations, concurrency, payments, deployment/CI, MCP security boundaries, spec changes.
- How to call, verify, review and retry: follow the `local-coder-delegation` skill.
